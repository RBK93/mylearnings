### Github Projects

- classic vs new projects
  - you cannot create a new classic project, can only be created if an org has atleast one classic project
  - made up of issues, PR and notes ( similar to boards in new projects)
  
  - classic projects are created at repo level ( in new they are created at org level and can be attached to any repo)
-  - migrate to new projects

> basically like a JIRA board in github ?

- Board ( Kandban)
- RoadMap ( Gannt chart )

### Project Creation
- create by navigting to projects section in github account > new project 
- Choose Table, Board or Raodmap
- You can even choose the default repor for the project ( its optional)
- Click on project name to go to settings and update the description and readme of the project 
- you can also control the visibility, copy, close and delete the project from the settings page 
- you have option to view the insights on the project ( use the menu option from top right)
- you can update the layout of the project from the view menu on porject page 
- #### Access Management
- - you can collaborate on a project by sharing access to your project from the settings> manage access page 
- #### Adding Custom Fields 
 - Settings > Fields section > edit old/add new field and choose color properties
    - Field types - text, date, single/multi selection, iteration ( sprint etc ) 
- #### Roadmap
  - marker

  - zoom by month, qtr, yr
