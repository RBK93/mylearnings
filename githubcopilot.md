### Copilot 
#### what 
- code assistant
- LLM
- based on GPT 
    - customized version of GPT  (LLM)
    - sply good for python java ruby
- LLM
    - formulas used to predict events
    - LLM > token, number or word
- How they work
    - Tokenization
        - training - absorb all data and tokenize words characters symbols as tokens( numbers)
        - more complex language = more complex vocabulary 
        - size of the language and the amount of information that we provide can affect the cost of using the model( cpu power and usage)
    - Training phases
        - for different inputs the models try to determine the probability of the next piece of code / token should be .
        - this is done continously until the model writes back our responses
        - Most training is a statistical analysis of a token that determinse the most likely next token this is followed by human led reinforcement so the predictions become better over time
#### Copilot for business
- send info from user computer to AI, they retain info to train the models
- regular copilot the prompts created in chat and the prompts that are generated when you pause while typing code > all these are retained by Regular Copilot 
- Copilot Business send these prompt in real time only and does not retain
- suggestion returned by model also are not retained 
- some usage data retained for R&D
- Allows Organization Policies ( allow/disallow match public code)
